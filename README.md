# Expense Tracker

A lightweight, completely offline, and single-file web application to track shared expenses, split bills, and manage receipts with friends and family. 

## 🌟 Key Features

* **100% Offline & Private:** Everything runs entirely in your browser. No backend server, no cloud syncing, and no data leaves your device. Data is securely saved in your browser's local database (IndexedDB).
* **Smart Splitting:** Split bills equally, by exact amounts, or by percentages.
* **Balance Calculation:** Automatically calculates "Who owes whom" using a smart algorithm to minimize the total number of transactions needed to settle up.
* **Attachments:** Attach large receipt images and PDFs directly to your expenses without crashing your browser.
* **Visual Analytics:** View your spending habits through clean, interactive pie and doughnut charts.
* **Export & Import:** * Export to **CSV** to view your data in Excel or Google Sheets.
  * Download a **Full Backup (.json)** including all large attachments to safely move your data to another device.

## 🚀 How to Use

1. **No Installation Required:** Since this is a single HTML file, you don't need to install anything or set up a server.
2. **Open the App:** Simply double-click the `Expense Tracker.html` file to open it in any modern web browser (Chrome, Safari, Edge, Firefox).
3. **Add Friends:** Go to the "People" tab to add the names of people you are splitting bills with.
4. **Add Expenses:** Go to the "Add" tab, enter the bill details, choose who paid, and select how to split it.
5. **Check Balances:** Go to the "Analytics" tab to see exactly who owes what and view your charts.

## ⚙️ Settings

* **Customize Currency:** Change your default currency symbol (e.g., ₹, $, €, £) from the Settings menu.
* **Your Name:** Set your personal name so the app knows which share of the bills belongs to you.

## 📱 Mobile Friendly

The app is built with a responsive, app-like design. You can send the HTML file to your phone and open it in your mobile browser for a native app-like experience.
